# ai-
这里是我压力ai写的插件，力求让自己的ai机器人更像一个人（大雾

mood-memory系是ai的记忆与心情联合系统，她添加了记忆库，并使用中文作为直接索引命中（经过实测命中率能到80%）。心情系统有着七维（开心，踏实，甜蜜，心疼，担心，难过，吃醋） 心情条。这些值的大小将直接影响ai的语气。详情看包内readme。当前也完成了该系统接入泰拉瑞亚，并作为媒介联动到平常聊天，甚至其他模块，毕竟拥有同份记忆不是（。并且加了专门的游戏技能条目库，让他在玩游戏时执行指令可以调用库里的技能，命中原理和记忆库基本一致，只是为了增加命中率新加了固定的key规则。详细的细节可以看ai写的readme。
